  (versi, changelog, batasan SDK/platform, status discontinued).

  `docs/WORKFLOW.md`) terhadap kode.
- Eksekusi: `flutter analyze`, `flutter test`, `build_runner`, `flutter build apk --debug`
  pada host Linux.
