# Taste
- Prefers all project documentation and planning documents to be written in Bahasa Indonesia (Indonesian), even when working on apps whose code/content is in English. Confidence: 0.9
- Prefers feature-first modular architecture: code organized by feature (e.g. `lib/features/<feature>/`) with shared core/data/services layers, rather than pure layered (core/data/screens/services) structure. Confidence: 0.9
- When a project is slated for a full refactor, prefers documentation (agents.md, rules, workflow, design system, feature specs) to be written fresh as a target-state contract — describing the desired new architecture and features, not the current implementation — so the codebase is rebuilt to match the docs. Confidence: 0.9
- Prefers the app's default theme to be light mode (`ThemeMode.light`), with dark/system as user-selectable options rather than the default. Confidence: 0.9
- Prefers a romantic, warm, intimate visual aesthetic for the app: blush-toned background, rose pink/mauve accents, soft surfaces, and romantic gradients — i.e., light mode designed around a "Romantic Light" palette rather than generic white. Confidence: 0.85
- When undertaking a refactor, prefers a full, complete refactor of the entire codebase to match the target docs, rather than partial or incremental changes. Confidence: 0.8
